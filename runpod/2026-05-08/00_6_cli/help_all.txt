==== bin/dario-infer
dario-infer: Go wrapper around the C ./infer_v4 binary.

usage:
  dario-infer [flags] "prompt text"

flags:
  --voice NAME       voice to speak through (default leo)
                     valid: leo, arianna, yent, resonance-yent, base, leo24m
  --weights PATH     override the resolved weights file
  --temp F           sampling temperature (default = voice default)
  --topk N           top-k cutoff (0 = disabled, default = voice default)
  --max-tokens N     max generation length (default 80)
  --seed N           RNG seed for infer_v4 (default 0 = wall clock)
  --binary PATH      override path to the infer_v4 binary
  --timeout DUR      kill inference after this long (default 2m)
==== bin/dario-dialogue
dario-dialogue: chain / dialogue / duet / trialogue modes for the dario voices.

usage:
  dario-dialogue --mode MODE [flags]

modes:
  chain      — one voice, KK injects between rounds
  dialogue   — interactive REPL with KK and dario field
  duet       — two voices via two goroutines + channel turn coordination
  trialogue  — three voices via three goroutines

common flags:
  --voice NAME       primary voice (default leo)
  --voice2 NAME      second voice (duet/trialogue)
  --voice3 NAME      third voice (trialogue)
